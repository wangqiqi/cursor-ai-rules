According to Cursor official documentation, you can import rules from external sources to reuse existing configurations or use rules from other tools.

#### Supported Import Methods

**GitHub Repository Import (Recommended):**
1. Open **Cursor Settings → Rules, Commands**
2. Click `+ Add Rule` next to `Project Rules`
3. Select `Remote Rule (GitHub)`
4. Paste the GitHub repository URL containing the rule
5. Cursor will pull the rule and sync it to your project

**Agent Skills Import:**
1. Open **Cursor Settings → Rules**
2. Find the **Import Settings** section
