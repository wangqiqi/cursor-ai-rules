# 🎨 Frontend Design

Create distinctive, production-grade frontend interfaces with high design quality. This skill generates creative, polished code and UI design that avoids generic AI aesthetics.

## When to Use

- When users ask to build web components, pages, or applications
- For creating websites, landing pages, dashboards, or React components
- When styling or beautifying web UI elements
- For HTML/CSS layouts that need distinctive, high-quality design
- When avoiding generic or repetitive AI-generated aesthetics

## Instructions

### Design Principles

1. **Distinctive Aesthetics**: Create unique, memorable designs that stand out from generic templates
2. **Production Quality**: Ensure all code is production-ready with proper structure and performance
3. **Creative Approach**: Combine functionality with artistic design elements
4. **Modern Standards**: Use current web development best practices and technologies

### Implementation Guidelines

#### Component Creation
- Use semantic HTML with proper accessibility attributes
- Implement responsive design with mobile-first approach
- Apply modern CSS techniques (Flexbox, Grid, CSS Custom Properties)
- Include proper state management for interactive elements

#### Styling Best Practices
- Create cohesive color palettes and typography systems
- Use consistent spacing and sizing scales
- Implement smooth animations and transitions
- Ensure cross-browser compatibility

#### Code Quality
- Write clean, maintainable CSS and JavaScript
- Use meaningful class names and component structures
- Include proper error handling and edge cases
- Optimize for performance and loading speed

#### Landing Page Design
- Hero section with compelling visual hierarchy
- Feature showcase with engaging animations
- Call-to-action buttons with hover effects
- Footer with organized link sections

## Dependencies

- HTML5 and CSS3 support
- Modern JavaScript (ES6+)
- Recommended: React, Vue, or similar framework for complex applications
