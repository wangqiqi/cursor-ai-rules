# API Design

Professional API design: RESTful resources, GraphQL schemas, OpenAPI 3.0, versioning, auth, and performance.

## When to use

- New or refactored HTTP/GraphQL APIs
- OpenAPI/Swagger generation or review
- Consistency, security, or scalability review of existing APIs

## Workflow

1. Clarify entities, operations, auth, and consumers.
2. Choose style (REST vs GraphQL vs hybrid) and versioning strategy.
3. Draft resources/paths or schema; add error model and pagination.
4. Validate with OpenAPI (or schema linter) and security checklist.
