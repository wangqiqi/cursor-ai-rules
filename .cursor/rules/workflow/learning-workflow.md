# 🧠 学习工作流 (Learning Workflow)

*版本: v1.0.0 | 最后更新: {{GENERATION_TIME}} | 作者: wangqiqi (https://github.com/wangqiqi)*

## 🎯 核心功能

智能学习新技术栈，为开发者提供个性化的学习路径和实践指导。

### ⚠️ 学习原则

**MUST** 遵循以下学习原则：
- **MUST** 从实际项目需求出发学习
- **NEVER** 只看理论不实践
- **ALWAYS** 编写可运行的代码示例
- **MUST** 完成完整的练习项目
- **DO NOT** 跳过基础直接学习高级特性

### 📚 学习内容类型

#### 编程语言学习
```bash
# 学习新编程语言
@master 学习Rust语言
@master 掌握Go并发编程

# 提供：
- 语法基础
- 核心概念
- 最佳实践
- 项目示例
```

#### 框架技术学习
```bash
# 学习前端框架
@master 学习React生态
@master 掌握Vue 3组合式API

# 包含：
- 框架核心概念
- 状态管理
- 路由处理
- 测试策略
```

#### 工具链学习
```bash
# 学习开发工具
@master 学习Docker容器化
@master 掌握Git工作流

# 涵盖：
- 工具安装配置
- 基本使用方法
- 高级功能
- 生产环境应用
```

## 🔄 学习流程

### 1. 评估当前水平
- 分析现有知识基础
- 确定学习目标
- 制定学习计划

### 2. 个性化学习路径
- 根据经验定制内容
- 分阶段学习安排
- 难度渐进递增

### 3. 实践指导
- 提供代码示例
- 创建练习项目
- 实时反馈和建议

### 4. 进度跟踪
- 学习进度记录
- 知识点掌握情况
- 薄弱环节强化

## 📊 学习资源

### 官方文档
- **权威资料**: 官方文档和规范
- **版本适配**: 当前最新版本内容
- **更新同步**: 跟踪最新变化

### 实践项目
- **渐进式项目**: 从简单到复杂
- **真实场景**: 模拟生产环境
- **最佳实践**: 行业标准应用

### 社区资源
- **优质教程**: 精选学习资源
- **问答社区**: 问题解决方案
- **开源项目**: 实际应用案例

## 🎯 学习模式

### 自主学习
```
用户主动发起学习：
- 指定学习主题
- 选择学习深度
- 自定义学习节奏
```

### 推荐学习
```
系统基于项目分析推荐：
- 补充知识盲点
- 提升技术栈深度
- 扩展技能边界
```

### 项目驱动学习
```
在项目开发中学习：
- 遇到问题即时学习
- 项目需求驱动学习
- 实践与理论结合
```

## 📈 学习效果评估

### 知识掌握度
- **理论理解**: 概念和原理掌握
- **实践能力**: 代码编写熟练度
- **问题解决**: 调试和优化能力

### 学习进度
- **完成度**: 学习内容的覆盖率
- **熟练度**: 技能的应用熟练程度
- **独立性**: 无需指导的解决能力

### 持续改进
- **学习习惯**: 主动学习能力的培养
- **知识体系**: 知识框架的构建
- **技术视野**: 技术选型和趋势把握
