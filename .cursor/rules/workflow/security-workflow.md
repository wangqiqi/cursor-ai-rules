# 🔒 安全工作流 (Security Workflow)

*版本: v1.0.0 | 最后更新: {{GENERATION_TIME}} | 作者: wangqiqi (https://github.com/wangqiqi)*

## 🎯 核心功能

自动化安全审计和漏洞检测，确保代码和配置的安全性。

### ⚠️ 安全原则

**MUST** 遵循以下安全原则：
- **NEVER** 提交包含已知漏洞的代码
- **MUST** 在代码合并前完成安全审计
- **ALWAYS** 使用最新版本的安全工具
- **MUST** 立即修复高危漏洞
- **DO NOT** 在生产环境使用默认凭据

### 🔍 安全审计类型

#### 代码安全审计
```bash
# 全面代码安全检查
@master 执行安全审计

# 检查内容：
- SQL注入漏洞
- XSS攻击防范
- CSRF保护
- 认证授权机制
- 输入验证
- 敏感信息泄露
```

#### 依赖安全检查
```bash
# 检查第三方依赖
@master 检查依赖安全

# 包含：
- 已知漏洞扫描
- 许可证合规性
- 过时依赖检测
- 供应链安全
```

#### 配置安全评估
```bash
# 配置文件安全检查
@master 评估配置安全

# 审核：
- 权限设置
- 密钥管理
- 网络配置
- 日志安全
```

## 🔄 安全工作流程

### 1. 威胁建模
- 识别潜在威胁
- 评估风险等级
- 确定保护措施

### 2. 漏洞扫描
- 静态代码分析
- 动态测试执行
- 依赖项检查

### 3. 风险评估
- 漏洞严重性分级
- 影响范围分析
- 修复优先级排序

### 4. 修复建议
- 提供修复方案
- 生成安全补丁
- 更新安全策略

## 🛡️ 安全工具集成

### 代码分析工具
- **ESLint Security**: JavaScript安全规则
- **SonarQube**: 综合代码质量和安全
- **Bandit**: Python安全分析
- **Safety**: Python依赖安全检查

### 漏洞扫描器
- **OWASP ZAP**: Web应用安全扫描
- **Snyk**: 开源依赖漏洞检测
- **Clair**: 容器镜像漏洞扫描
- **Trivy**: 云原生安全扫描

### 合规检查
- **License Checker**: 开源许可证合规
- **Secret Scanner**: 敏感信息检测
- **Configuration Auditor**: 配置安全审计

## 📋 安全策略

### 防御深度
- **多层防护**: 网络、应用、数据多层保护
- **最小权限**: 基于角色的访问控制
- **安全默认**: 安全优先的默认配置

### 持续监控
- **实时监控**: 安全事件实时检测
- **定期审计**: 定时安全评估
- **自动响应**: 威胁自动响应机制

### 合规要求
- **行业标准**: OWASP、NIST等标准遵循
- **法规合规**: GDPR、SOX等法规要求
- **最佳实践**: 安全领域最佳实践应用

## 🚨 安全事件响应

### 事件分类
- **高危漏洞**: 立即修复，停止部署
- **中危问题**: 计划修复，设置监控
- **低危建议**: 记录改进，逐步优化

### 响应流程
1. **检测**: 自动扫描发现问题
2. **评估**: 安全团队评估风险
3. **修复**: 开发团队实施修复
4. **验证**: 重新扫描确认修复
5. **记录**: 更新安全日志和报告

### 预防措施
- **安全培训**: 开发者安全意识培训
- **代码审查**: 强制安全代码审查
- **自动化测试**: 安全测试集成到CI/CD
