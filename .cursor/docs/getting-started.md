## 📋 系统要求

### 基础环境
- **操作系统**: Linux, macOS, Windows
- **Cursor编辑器**: v0.40+

### 可选环境 (推荐)
- **Node.js**: 16.0+ (用于Web界面)
- **npm**: 7.0+ (用于依赖管理)

## ⚡ 一键安装

### 方法1：智能Master (推荐)
```bash
# 1. 克隆项目
git clone https://github.com/wangqiqi/cursor-ai-rules.git

# 2. 复制到你的项目
cp -r cursor-ai-rules/.cursor /path/to/your-project/

# 3. 进入项目目录
cd /path/to/your-project

# 4. 运行智能初始化
./.cursor/core/init.sh
```

### 方法2：手动设置
```bash
# 1. 复制.cursor目录到项目根目录
cp -r /path/to/cursor-ai-rules/.cursor ./

# 2. 验证安装
./.cursor/core/init.sh --help
```

## ❓ 常见问题

### 安装问题
**Q: init.sh执行失败？**
A: 确保有执行权限 `chmod +x .cursor/core/init.sh`

**Q: 命令找不到？**
A: 检查.cursor目录是否在项目根目录

### 使用问题
**Q: @master命令无响应？**
A: 确保在Cursor编辑器中输入，并在对话框中发送

**Q: 宪法保护机制？**
A: 当检测到项目创建意图时，系统会先讨论需求再执行
