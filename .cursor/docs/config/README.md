# 🔧 配置目录

此目录包含Cursor AI Rules系统的配置文件。

## 📄 文件说明

- **`intelligent_evolution.config.json`** - 智能进化系统配置
  - 感知设置和监控参数
  - 进化触发器和规则调整
  - 学习系统和隐私控制

- **`templates.config.json`** - 项目初始化配置模板
  - 项目模板和协作设置
  - 技术要求和质量门禁
  - 团队动态和开发工作流

## 🔄 使用方法

这些配置文件可以修改以自定义AI协作系统的行为。更改会立即生效，无需重启系统。

## 💾 备份

重要提示：在进行更改前，请务必备份配置文件。系统可能会自动创建 `.backup` 文件以用于恢复。
