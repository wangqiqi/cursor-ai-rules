## ⚙️ 配置与个性化

### 5层配置体系

#### 1. 系统默认配置 (最低优先级)
- 位置: `config/system-defaults.json`
- 内容: 内置默认值

#### 2. 全局配置
- 位置: `config/global.json`
- 内容: 跨项目通用设置

#### 3. 项目配置
- 位置: `config/project.json`
- 内容: 项目特定配置

#### 4. 用户配置
- 位置: `~/.cursor/config/user.json`
- 内容: 个人偏好设置

#### 5. 运行时配置 (最高优先级)
- 位置: `config/runtime.json`
- 内容: 动态生成的配置
