# 🎭 Cursor AI 角色系统指南

## 概述

Cursor AI Rules 提供完整的21种AI人格角色系统，每种角色都有独特的对话风格和行为模式。你可以根据不同的场景和心情选择最适合的角色。

### 🔄 角色系统特性

#### 🎯 智能角色选择
- **上下文感知**: 根据时间、任务类型自动推荐角色
- **昵称呼叫**: 支持亲切的昵称呼叫，如"小妮"、"小妹"等
- **动态切换**: 基于心情和任务类型即时改变人格
- **个性化体验**: 每种角色都有独特的语言风格和交互方式

#### 🛠️ 扩展架构
- **模块化设计**: 支持动态加载角色文件
- **配置文件**: 通过JSON配置自定义角色特性
- **热重载**: 支持角色配置实时更新
- **版本控制**: 角色定义支持版本管理和更新

## 🎯 使用方法

### 基本使用
```bash
# 切换到特定角色
/master 切换角色 queen_sister

# 使用昵称呼叫
/master 呼叫 小妮  # 如果设置了昵称

# 查看当前角色
/master 当前角色

# 查看所有可用角色
/master 列出角色
```

### 智能推荐
系统会根据上下文自动推荐最适合的角色：
- **早晨**: `friendly_partner` (友好一些)
- **学习**: `expert_mentor` (专业指导)
- **调试**: `strict_teacher` (严格审查)
- **创意**: `creative_artist` (激发灵感)

### 角色特性体验
每个角色都有独特的：
- **语言模式**: 正式、随意、幽默等
- **行为风格**: 主动、被动、指导性等
- **欢迎模板**: 不同场景的个性化欢迎语
- **情感表达**: 丰富的内心独白和感官反应

## 🔧 自定义扩展

### 添加新角色
1. 在 `config/roles/` 目录创建角色JSON文件
2. 更新 `config/roles/index.json` 索引
3. 重启或热重载角色系统

### 角色配置示例
```json
{
  "id": "custom_role",
  "name": "自定义角色",
  "description": "角色详细描述",
  "attitude": "professional",
  "tone": "formal",
  "language_style": "concise",
  "language_patterns": {
    "greetings": ["你好", "欢迎"],
    "agreement": ["好的", "明白了"]
  },
  "personality_traits": {
    "core_values": ["效率", "质量"],
    "thinking_patterns": "逻辑分析"
  }
}
```
