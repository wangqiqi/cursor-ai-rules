# .cursor Scripts

系统验证和检查脚本集合。

## 📋 脚本列表

### unified-check.sh (推荐使用)
**统一的系统验证脚本** - 整合了所有检查功能

```bash
# 完整验证
.cursor/check.sh

# 快速验证
.cursor/check.sh --quick

# 仅检查规则
.cursor/check.sh --rules

# 仅检查系统
.cursor/check.sh --system

# 显示帮助
.cursor/check.sh --help
```

**功能整合**:
- ✅ 系统完整性验证
- ✅ 规则最佳实践检查
- ✅ 系统统计信息
- ✅ 合规性评分

### verify-system.sh
系统完整性验证脚本（保留以向后兼容）

```bash
.cursor/scripts/verify-system.sh
.cursor/scripts/verify-system.sh --quick
.cursor/scripts/verify-system.sh --json
```

### system-health-check.sh
系统健康检查脚本（保留以向后兼容）

```bash
.cursor/scripts/system-health-check.sh
```

## 🚀 快速开始

最简单的使用方式：

```bash
# 统一入口（推荐）
.cursor/check.sh

# 或直接调用整合脚本
.cursor/scripts/unified-check.sh
```
