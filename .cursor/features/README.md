# 🎯 Cursor AI Rules - 功能层

这个目录包含了Cursor AI Rules系统的所有扩展功能模块。

## 📁 目录结构

```
features/
├── automation/     # 自动化工具和脚本
│   ├── hooks/     # 事件钩子系统
│   └── scripts/   # 自动化脚本
├── skills/        # 专业技能库
└── hooks/         # 钩子配置文件
```

## 🔧 功能模块说明

### Automation (自动化工具)
- **Hooks**: 事件驱动的自动化处理
- **Scripts**: 可执行的自动化脚本

### Skills (专业技能)
- 技术栈特定的专业技能
- 代码生成和处理能力
- 文档和内容处理技能

### Hooks (钩子系统)
- 事件触发的自动化处理
- 生命周期钩子管理


## 🚀 使用方法

功能层组件通过统一的命令入口进行调用：

```bash
# 激活技能
@master 我想使用PDF处理技能

# 运行自动化脚本
@master 执行代码质量检查

# 触发钩子事件
@master 提交代码  # 自动触发pre-commit钩子
```

## 🔌 扩展开发

### 添加新技能
1. 在 `skills/` 目录创建技能文件
2. 更新 `commands/capability-map.json`
3. 添加相应的文档和示例

### 添加新钩子
1. 在 `hooks/` 目录添加钩子脚本
2. 更新 `hooks.json` 配置
3. 测试钩子触发逻辑

### 添加自动化脚本
1. 在 `automation/scripts/` 目录添加脚本
2. 确保脚本有适当的权限
3. 更新相关文档
