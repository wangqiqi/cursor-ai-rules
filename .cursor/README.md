## 🏗️ 系统架构

### 🎯 三大无关性设计理念

#### 📦 项目无关性 (Project Agnostic)
- ✅ **即插即用**: 复制 `.cursor/` 到任何Git项目，立即获得完整AI能力
- ✅ **自动适配**: 智能检测项目类型、技术栈和环境配置
- ✅ **多项目支持**: 支持在多个项目中同时使用同一套AI系统

#### 🖥️ 系统无关性 (System Agnostic)
- ✅ **跨平台兼容**: Linux/macOS/Windows的完整支持
- ✅ **自动检测**: 操作系统类型和环境变量的智能识别
- ✅ **统一接口**: 屏蔽底层系统差异，提供一致体验

#### 👤 用户无关性 (User Agnostic)
- ✅ **AI核心独立**: 核心AI能力不依赖特定用户身份
- ✅ **数据隔离**: `.cursorGrowth/` 目录存储所有用户特定数据
- ✅ **隐私保护**: 用户偏好、学习数据完全本地化

### 🗂️ 双目录架构设计

#### **`.cursor/`** 🧠 **AI核心系统**
```
.cursor/
├── commands/      # 命令处理器 - 统一的AI接口
├── core/         # 核心引擎 - 智能算法和业务逻辑
├── rules/        # 规则体系 - 三大公理强制执行
├── skills/       # 技能库 - 24个专业技能扩展
├── docs/         # 文档体系 - 完整用户指南
├── features/     # 高级功能 - 自动化和集成
├── config/       # 系统配置 - 默认设置和模板
└── web/          # Web界面 - 可选图形界面
```
**特性**: 可移植、可复制、标准化、版本化

#### **`.cursorGrowth/`** 🌱 **用户生长数据**
```
.cursorGrowth/
├── config/       # 用户配置覆盖 (debug-config.json, overrides.json)
├── user_data/    # 用户偏好和交互历史
├── project/      # 项目特定标识符 (project_id)
├── ai/          # AI学习数据和技能实例
├── cache/       # 运行时缓存
├── monitoring/  # 系统监控数据
├── analytics/   # 使用分析数据
└── integrations/# 第三方服务集成配置
```
**特性**: 隐私保护、个性化学习、数据隔离、跨会话持久化

#### 架构优势
- **🔄 可复制性**: `.cursor` 目录可在任意项目间复制
- **🔒 隐私保护**: `.cursorGrowth` 数据完全私有不共享
- **👥 协作友好**: 团队共享配置，每个人的数据都是独立的
- **⚡ 性能优化**: 本地缓存和学习数据提升响应速度
- **🎯 三大无关性**: 实现真正的项目、系统、用户无关
