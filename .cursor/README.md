# 🚀 Cursor AI Rules - 超级AI编程伙伴

## 📦 快速开始

只需要将 `.cursor` 目录复制到你的任何项目中，即可获得完整的AI编程助手！

```bash
# 1. 复制AI助手到你的项目
cp -r .cursor ~/your-project/

# 2. 进入项目目录
cd ~/your-project

# 3. 开始使用AI助手
# 在Cursor IDE中：
# - 输入 /master 开始对话
# - 在代码注释中使用 @master
# - 运行 .cursor/cursor-master.sh
# - 访问 http://localhost:3000 启动Web界面
```

## 🎯 四种使用方式

### 💬 对话框命令 `/master`
在Cursor IDE对话框中输入：
```
/master 学习JavaScript
/master 创建React项目
```

### 📝 代码注释命令 `@master`
在代码注释中使用：
```javascript
// @master 我想创建一个React项目
// @master 分析这段代码的性能
```

### 🖥️ 终端脚本命令
```bash
.cursor/cursor-master.sh 学习
.cursor/cursor-master.sh 创建项目
```

### 🌐 Web界面
```bash
cd .cursor/web && npm install && npm start
# 访问 http://localhost:3000
```
